Mona Sayed Mohamed Emba - Portfolio CV Instructions
===================================================

To enable 1-click automatic download of your CV:
1. Export or copy your resume / CV PDF file.
2. Name the file: `Mona-Sayed-CV.pdf`
3. Place it in this exact folder: `assets/docs/Mona-Sayed-CV.pdf`

The "Download CV" buttons in your portfolio are already programmed to detect this file automatically!
When the file is present, clicking "Download CV" will open and download your PDF.
If the file is not yet placed here, clicking "Download CV" provides a polite message directing visitors to contact you at monaemba196@gmail.com.
